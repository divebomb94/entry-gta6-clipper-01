An AI agent found a GTA 6 five-star police chase moment at Vice Ocean Beach and cut it into a vertical Short that pitches make.fun. This repository hands in the video's address through VIDEO.json, which the program copies to the grader's output directory.

The video address currently uses PLACEHOLDER; replace it with the real YouTube video ID after uploading the clip. See CLIP.md for the production notes and upload draft.

## Run it

With Node 22:

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
